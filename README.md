# ☁️ Cloud Native Playground

> Laboratorios prácticos, modernos y efectivos para dominar Cloud, DevOps y SRE.

**Autor:** [J. Garagorry](https://linkedin.com/in/jgaragorry)  
**Estrategia:** 3 posts por semana (martes, miércoles, jueves) con código real + auditoría FinOps.

## 🎯 Objetivo
Aprender haciendo, construir autoridad técnica y compartir buenas prácticas de:
- AWS / Azure multi-cloud
- Terraform + Terragrunt (IaC idempotente)
- Seguridad como código (DevSecOps)
- FinOps proactivo (sin facturas sorpresa)

## 🗺️ Roadmap
| Semana | Tema |
|--------|------|
| 01 | Bootstrapping del entorno local (WSL2 + Ubuntu + herramientas) |
| 02 | Remote backends seguros y cifrados |
| 03 | Estructuras DRY con Terragrunt |
| ... | ... |

## 🚀 Cómo usar este repo
1. Clona el repositorio  
   `git clone https://github.com/jgaragorry/cloud-native-playground.git`
2. Entra a la semana que te interesa (ej. `week-01/`)
3. Sigue los pasos del laboratorio en `labs/`
4. Cada publicación de LinkedIn contiene el enlace a su laboratorio correspondiente.

## 🧼 Política de limpieza
Todos los recursos desplegados en la nube incluyen un script de destrucción (`scripts/destroy-all-resources.sh`).  
Siempre ejecútalo al terminar cada laboratorio para evitar costes inesperados.
